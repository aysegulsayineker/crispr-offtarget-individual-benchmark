# Individual-level benchmark of CRISPR-Cas9 off-target activity predictors

Population-scale re-analysis of cellular GUIDE-seq-2 and rhAmpSeq off-target measurements in
95 genetically distinct human donors, asking a question that pooled benchmarks cannot answer:
**how well do off-target predictors rank risk between individuals at the same genomic site?**

The analysis contains four components:

1. **Within-site decomposition** — Spearman correlation after centring prediction and measurement
   within each off-target site, which removes between-site variation and isolates the
   genotype-driven, between-donor component.
2. **Noise ceiling** — an unbiased ANOVA variance-components estimate of the fraction of
   within-site variance that is explainable in principle, obtained from donors who share
   identical haplotype pairs at a site (such donors receive identical predictions, so their
   measured spread estimates irreducible assay noise).
3. **Ancestry-stratified calibration audit** — cross-fitted isotonic calibration followed by a
   donor-level permutation test of ancestry-dependent residual bias.
4. **Split conformal prediction and decision rules** — marginal and Mondrian (per-ancestry)
   conformal intervals, their empirical coverage and width, and the sensitivity / flag rate of
   point-prediction and conformal-upper-bound screening rules across indel-fraction thresholds.

Five published predictors are evaluated as released, without retraining: CHANGE-net, CFD,
CRISOT, CRISPRoff and CRISPRnet.

## Data provenance

All inputs are public and are downloaded by `src/download_data.sh`. No credentials are needed.

| Source | Accession / URL | Content |
|---|---|---|
| NCBI GEO | **GSE346736** (`GSM10039759_All_1115sites_95_donor.csv.gz`) | Cellular GUIDE-seq-2 off-target profiles, 1,115 on/off-target sites x 95 donors, with per-haplotype predictor scores |
| NCBI GEO | **GSE286299** (`GSE286299_rhamp_seq_merged_table.csv.gz`) | rhAmpSeq targeted amplicon validation (indel %) |
| 1000 Genomes Project | `integrated_call_samples_v3.20130502.ALL.panel` | Sample-to-population panel used for the independent ancestry-label integrity check |
| gnomAD v4 | GraphQL API, dataset `gnomad_r4`, accessed 2026-11-03 | Per-ancestry allele frequencies for the nine gnomAD genetic ancestry groups over the 1,115 site intervals |

Both GEO series were generated by the source study:

> Population-scale cellular GUIDE-seq-2 and biochemical CHANGE-seq-R profiles reveal human
> genetic variation frequently affects Cas9 off-target activity. *bioRxiv* 2025.
> PMID 39990392, doi:[10.1101/2025.02.10.637517](https://doi.org/10.1101/2025.02.10.637517)

That study established that human genetic variation frequently alters Cas9 off-target activity
and introduced the CHANGE-net predictor. This repository does not re-derive those results; it
re-uses the released measurements and scores to quantify how well predictors resolve
**between-individual** differences, and what the ceiling on that performance is.

## Reproducing the analysis

```bash
conda env create -f environment.yml
conda activate crispr-offtarget-individual

bash src/download_data.sh          # ~1 GB into ./data, public FTP, no credentials
python src/analysis.py             # ~2.5 min on 8 CPU cores -> results/*.csv
python src/make_figures.py         # -> figures/figure1..4 .png (300 dpi)
pytest -q tests                    # smoke test on the result tables
```

`src/analysis.py` is single-threaded except for the libraries' own BLAS calls; the ~2.5 min
runtime is dominated by the 300 site-level bootstrap replicates used for the within-site
correlation and noise-ceiling confidence intervals. All random draws are seeded (`SEED = 0`,
and `default_rng(1)` for the decision-rule splits), so the result tables are bit-reproducible.

## Repository layout

```
src/download_data.sh    public data download
src/analysis.py         full analysis; writes results/*.csv
src/make_figures.py     figures 1-4; reads results/*.csv only
results/                result tables (committed, so figures and tests run without the raw data)
figures/                publication figures (300 dpi PNG)
tests/test_results.py   smoke test: outputs exist and headline numbers match
```

## Result tables

| File | Contents |
|---|---|
| `benchmark_noise_ceiling.csv` | pooled and within-site Spearman rho with bootstrap CIs, partial R^2, explainable-variance fraction, ceiling rho and % of ceiling attained, per assay x model |
| `calibration_by_ancestry.csv` | MAE and signed residual bias per population, bias spread, donor-permutation p and BH-adjusted p |
| `conformal_coverage.csv` | empirical coverage, its SD across splits, and interval width for marginal and Mondrian conformal intervals, per assay x model x ancestry |
| `decision_rule_eval.csv` | sensitivity and flag rate of point and conformal-upper screening rules over eight indel-% thresholds, per model x ancestry |
| `per_guide_within_rho.csv` | within-site rho per guide RNA |
| `integrity_checks.csv` | row/donor/site counts, 1000 Genomes label concordance, missingness audit |
| `data_dictionary.csv` | column types, non-null counts and cardinalities of the merged input table |
| `discrimination_by_ancestry.csv` | pooled Spearman rho per 1000 Genomes population and the max-min spread, per assay x model |
| `measured_descriptives.csv` | median, quartiles and range of each measured outcome, needed to interpret conformal interval widths |
| `gnomad/gnomad_site_ancestry.csv` | per site x ancestry group: variant counts, max AF, carrier probability, PAM creation/disruption |
| `gnomad/gnomad_guide_summary.csv` | per guide x ancestry group: sites altered at the 1% and 5% thresholds, PAM events |
| `gnomad/gnomad_cohort_gap.csv` | sites altered per group and per threshold that the cohort's four populations cannot see |
| `gnomad/gnomad_ancestry_methods.md` | exact GraphQL query, access date, version, assumptions, success/failure counts |
| `gnomad/gnomad_raw_cache.tar.gz` | raw gnomAD API responses, so the tables regenerate without re-querying |

The gnomAD extension is produced by `src/gnomad_ancestry_analysis.py`, which is independent of
`src/analysis.py` and reads its cached API responses from `results/gnomad/`. Re-running it against
the live API takes roughly an hour because of rate limiting; regenerating the tables from the
cache is immediate.

## Data and code availability

All primary data are public: NCBI GEO accessions GSE346736 and GSE286299, and the 1000 Genomes
Project phase-3 sample panel. All analysis code, the exact result tables reported in the
manuscript, and the figure-generation script are in this repository and are released under the
MIT License. No restricted, controlled-access or individually identifying data were used; the
1000 Genomes samples are openly consented cell lines.
