# Individual-level benchmark of CRISPR-Cas9 off-target activity predictors

Population-scale re-analysis of cellular GUIDE-seq-2 and rhAmpSeq off-target measurements in
95 genetically distinct human donors, asking a question that pooled benchmarks cannot answer:
**how well do off-target predictors rank risk between individuals at the same genomic site?**

The analysis contains four components:

1. **Within-site decomposition** — rank association after percentile-transforming prediction and
   measurement *within each off-target site*, which removes between-site variation and isolates
   the genotype-driven, between-donor component.
2. **Haplotype-conditioned noise ceiling** — donors who share an identical, order-invariant
   haplotype pair at a site receive identical predictions, so their measured spread bounds what
   any sequence-based model could reach. The ceiling is computed on the same percentile scale and
   on the same rows as each model's own association (model-matched), and the attainment ratio
   carries a joint-bootstrap confidence interval in which numerator and denominator are
   recomputed together on every resample. A raw-scale variance-components version is reported as
   a sensitivity analysis, together with a site-averaged estimator.
3. **Ancestry-stratified calibration audit** — cross-fitted isotonic calibration followed by a
   donor-level permutation test of ancestry-dependent residual bias, with BH correction.
4. **Conformal prediction and decision rules** — marginal and Mondrian (per-ancestry) split
   conformal intervals under *two* exchangeability units, the site and the donor; a unit-level
   group-conformal variant that carries a genuine finite-sample guarantee; and the sensitivity
   and flag rate of point-prediction and conformal-upper-bound screening rules across
   indel-fraction thresholds.

Models are also compared to one another with **paired site-level bootstrap tests** (400
resamples, BH-corrected over 20 comparisons), so that claims of one model beating another are
tested rather than read off a ranking.

5. **Does the gap close?** — three further analyses ask whether the uncaptured between-donor
   signal is recoverable. Explicit variant features (substitution position, seed and PAM context,
   substitution type, burden, zygosity) are compared against the released scores on identical
   rows and folds, under leave-one-guide-out and repeated donor-held-out validation; a two-part
   formulation separates whether measurable editing occurs from how much; and a donor propensity
   carrying no sequence information at all is tested against a within-site permutation null and
   across the two assays. Variant features add nothing beyond the released scores, in-sample as
   well as out; the donor term does.

Five published predictors are evaluated as released, without retraining: CHANGE-net, CFD,
CRISOT, CRISPRoff and CRISPRnet.

## Data provenance

All inputs are public and are downloaded by `src/download_data.sh`. No credentials are needed.

| Source | Accession / URL | Content |
|---|---|---|
| NCBI GEO | **GSE346736** (`GSM10039759_All_1115sites_95_donor.csv.gz`) | Cellular GUIDE-seq-2 off-target profiles, 1,115 on/off-target sites x 95 donors, with per-haplotype predictor scores |
| NCBI GEO | **GSE286299** (`GSE286299_rhamp_seq_merged_table.csv.gz`) | rhAmpSeq targeted amplicon validation (indel %) |
| 1000 Genomes Project | `integrated_call_samples_v3.20130502.ALL.panel` | Sample-to-population panel used for the independent ancestry-label integrity check |
| gnomAD v4 | GraphQL API, dataset `gnomad_r4`, accessed 2026-11-03 | Per-ancestry allele frequencies for the nine gnomAD genetic ancestry groups over the 1,115 site intervals |

Both GEO series were generated by the source study:

> Flory AR, Lazzarotto CR, Li Y, et al. Frequent, context-dependent effects of human genetic
> variation on Cas9 activity revealed by population-scale GUIDE-seq-2 and deep combinatorial
> CHANCE-seq profiling. *bioRxiv* (preprint), revised version 2026; first posted 12 February 2025.
> PMID 39990392, doi:[10.1101/2025.02.10.637517](https://doi.org/10.1101/2025.02.10.637517)

That study established that human genetic variation frequently alters Cas9 off-target activity
and introduced the CHANGE-net predictor. This repository does not re-derive those results; it
re-uses the released measurements and scores to quantify how well predictors resolve
**between-individual** differences, and what the ceiling on that performance is.

## Reproducing the analysis

```bash
conda env create -f environment.yml
conda activate crispr-offtarget-individual

bash src/download_data.sh          # ~1 GB into ./data, public FTP, no credentials
python src/analysis.py             # ~9 min on 8 CPU cores -> results/*.csv
python src/make_figures.py         # -> figures/figure1..4 .png (300 dpi)
python src/make_tables.py          # -> results/table1..2 .csv, results/tables.{md,tex}
pytest -q tests                    # 13 checks on the result tables
```

`src/analysis.py` is single-threaded except for the libraries' own BLAS calls; the ~9 min
runtime (measured: 559 s wall on 8 cores) is dominated by the site-level bootstrap replicates —
300 for the within-site and ceiling confidence intervals, 400 for the paired model comparisons. All random draws are seeded (`SEED = 0`,
and `default_rng(1)` for the decision-rule splits), so the result tables are bit-reproducible.

## Repository layout

```
src/download_data.sh        public data download
src/analysis.py             benchmark, ceiling, calibration, conformal; writes results/*.csv
src/variant_features.py     donor-level variant features from the haplotype sequences

src/hurdle_model.py         two-part (detection / magnitude) formulation

src/fastboot.py             vectorised site-level bootstrap used by the above
src/make_figures.py         figures 1-4; reads results/*.csv only
src/make_figures2.py        figures 5-6; reads results/*.csv only
src/make_tables.py          tables 1-3; reads results/*.csv only

figures/                    publication figures (300 dpi PNG)
tests/test_results.py       17 checks: outputs exist, headline numbers and invariants hold
```

## Result tables

| File | Contents |
|---|---|
| `attainment_metric_consistent.csv` | **primary result**: rows and sites used per model, within-site association with bootstrap CI, model-matched ceiling, % of ceiling with joint-bootstrap CI, and the site-averaged sensitivity estimator |
| `table1_performance.csv`, `table2_ancestry_conformal.csv` | the two summary tables reported in the manuscript (`tables.md`, `tables.tex` are the same content as Markdown and LaTeX booktabs) |
| `paired_model_differences.csv` | paired site-level bootstrap differences between every model pair, with 95% CI, bootstrap p and BH-adjusted p |
| `benchmark_noise_ceiling.csv` | raw-scale sensitivity analysis: pooled and within-site Spearman rho, partial R^2, variance-components explainable fraction and ceiling, per assay x model |
| `calibration_by_ancestry.csv` | MAE and signed residual bias per population, bias spread, donor-permutation p and BH-adjusted p |
| `discrimination_by_ancestry.csv` | pooled Spearman rho per 1000 Genomes population and the max-min spread, per assay x model |
| `conformal_coverage.csv` | empirical coverage, its SD across splits, and interval width for marginal and Mondrian conformal intervals, per assay x model x ancestry, under both the site and the donor exchangeability unit |
| `group_conformal.csv` | unit-level group conformal (one conformity score per unit): unit coverage, row coverage and width — the variant with a genuine finite-sample guarantee |
| `decision_rule_eval.csv` | sensitivity and flag rate of point and conformal-upper screening rules over eight indel-% thresholds, per model x ancestry |
| `per_guide_within_rho.csv` | within-site association per guide RNA, on the primary percentile scale |
| `measured_descriptives.csv` | median, quartiles and range of each measured outcome, needed to interpret conformal interval widths |
| `integrity_checks.csv` | row/donor/site counts, 1000 Genomes label concordance, missingness audit |
| `gnomad/gnomad_site_ancestry.csv` | per site x ancestry group: variant counts, max AF, carrier probability, PAM creation/disruption |
| `gnomad/gnomad_guide_summary.csv` | per guide x ancestry group: sites altered at the 1% and 5% thresholds, PAM events |
| `gnomad/gnomad_cohort_gap.csv` | sites altered per group and per threshold that the cohort's four populations cannot see |
| `gnomad/gnomad_ancestry_methods.md` | exact GraphQL query, access date, version, assumptions, success/failure counts |
| `gnomad/gnomad_raw_cache.tar.gz` | raw gnomAD API responses, so the tables regenerate without re-querying |

The gnomAD extension is produced by `src/gnomad_ancestry_analysis.py`, which is independent of
`src/analysis.py` and reads its cached API responses from `results/gnomad/`. Re-running it against
the live API takes roughly an hour because of rate limiting; regenerating the tables from the
cache is immediate.

## Data and code availability

All primary data are public: NCBI GEO accessions GSE346736 and GSE286299, and the 1000 Genomes
Project phase-3 sample panel. All analysis code, the exact result tables reported in the
manuscript, and the figure- and table-generation scripts and are released under the
MIT License. No restricted, controlled-access or individually identifying data were used; the
1000 Genomes samples are openly consented cell lines.
